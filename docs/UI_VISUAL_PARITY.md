# BloodLink UI Visual Parity

## Reference

The read-only source of truth is `BloodBankSys` commit `24bc919646cc77c12df47ccb25df0aeb2a7681c7`. Its public layout, home page, branding, icon component, and production stylesheet define the target appearance. The standalone remains a Blazor WebAssembly application using its existing typed API clients and session services.

## Local Evidence

Screenshots and browser output are kept outside Git under `artifacts/ui-parity/`. They contain no credentials or authenticated personal data. The captured public views cover landing, registration, login, and mobile menu open/closed states. No authenticated screenshots are recorded until a user-approved test account is used interactively.

The current code is not production-ready for redeployment while the authenticated operational pages in this matrix remain materially different. Complete those presentation ports and role-based production checks before publishing.
